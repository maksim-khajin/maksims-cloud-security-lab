# Cloud Security Lab

Working notes, scripts and experiments from a network security engineer
moving into cloud, platform and AI security.

Background: 12+ years in enterprise networking and network security —
routing, IPsec/VPN, SASE, and multi-cloud test infrastructure.

## Layout

| Path | Contents |
|------|----------|
| `notes/` | Cheat sheets: commands that worked, mistakes made, how they were fixed |
| `scripts/` | Working scripts |
| `labs/` | Scratch work and experiments, per learning phase |
| `interview-backlog.md` | Questions from real interviews and the gaps they exposed |
